# PrimeNest Ohio

**Transforming Properties Into Safe Sanctuaries**

PrimeNest Ohio revitalizes undervalued properties into Smart Home Safe Havens — engineered for families navigating trauma and raising neurodivergent children. Built with React, TypeScript, Tailwind CSS, and Framer Motion.

---

## Tech Stack

| Layer | Technology |
|-------|------------|
| Framework | React 18 + TypeScript |
| Routing | React Router v6 |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Icons | Lucide React |
| Fonts | DM Sans (Google Fonts) |
| Map | Google Maps Embed |
| Build | Vite |

---

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
